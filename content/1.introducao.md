Bem-vindo às notas de versão do **Prosa**. Aqui você acompanha tudo o que muda no app a cada release — melhorias, correções e novidades — gerado automaticamente a partir das releases publicadas no [GitHub](https://github.com/4sllan/Prosa).

## Como navegar

- A **barra lateral** lista as versões disponíveis; selecione uma release para ver os detalhes.
- Cada versão tem **página própria** com tag, data de publicação e selo de **pré-release** quando aplicável.
- No fim de cada página, os links de **anterior** e **próxima** percorrem o histórico em sequência.

## Como ler as notas

As mudanças de cada release são agrupadas por tipo:

- **Enhancements** — novidades e melhorias de funcionalidades;
- **Fixes** — correções de bugs;
- **Documentation, Tests e CI** — trabalho de bastidor que mantém o app saudável;
- **Contributors** — quem contribuiu com a versão.

Cada página linka para a release oficial no GitHub, onde ficam os downloads, os assets e o diff completo entre versões.

## Última versão

Para baixar a versão mais recente, acesse as [releases no GitHub](https://github.com/4sllan/Prosa/releases) ou confira o histórico completo na [lista de releases](/releases).
