Welcome to the **Prosa** release notes. Here you can follow everything that changes in the app with each release — improvements, fixes and new features — generated automatically from the releases published on [GitHub](https://github.com/4sllan/Prosa).

## How to navigate

- The **sidebar** lists the available versions; select a release to see the details.
- Each version has **its own page** with tag, publication date and a **pre-release** badge when applicable.
- At the bottom of each page, the **previous** and **next** links walk through the history in order.

## How to read the notes

Each release's changes are grouped by type:

- **Enhancements** — new features and improvements;
- **Fixes** — bug fixes;
- **Documentation, Tests and CI** — behind-the-scenes work that keeps the app healthy;
- **Contributors** — who contributed to the version.

Each page links to the official release on GitHub, where you'll find the downloads, the assets and the full diff between versions.

## Latest version

To download the latest version, visit the [releases on GitHub](https://github.com/4sllan/Prosa/releases) or check the full history in the [releases list](/releases).
